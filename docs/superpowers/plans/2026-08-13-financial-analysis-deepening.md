### 3.4 四项深度财务分析

> 每项工具必须完成：**标准模板表 + 红旗判定 + 结论段**，三部分缺一不可。数据不足时明示"数据不足，跳过"（评分卡对应维度按 1 分计，见 §3.5），**禁止编造**。所有数字必须来自 A/B 级证据（财报/行情），推算项标 D 并说明方法。

#### 3.4.1 杜邦分解

**模板（3-5 年逐年）：**

| 年份 | ROE | 净利率 | 总资产周转率 | 权益乘数 |
|---|---|---|---|---|
| | | | | |

- 对每年相对上一年的 ΔROE 做**贡献分解**（连环替代法，说明方法）：净利率贡献、周转率贡献、杠杆贡献各占多少。
- **红旗**：ROE 提升主要由权益乘数上升驱动，且净利率或周转率在下降 → 增长靠加杠杆，不可持续。
- **结论段（必写）：** ROE 变动的真正驱动是谁？该驱动可持续吗？

#### 3.4.2 利润与现金流质量

**表 1 · 利润现金含量（3-5 年逐年）：**

| 指标 | 数值 |
|---|---|
| 收现比 = 销售商品、提供劳务收到的现金 / 营业收入 | |
| 经营现金流 / 净利润 | |
| 剔非净利率（扣除非经常损益后） | |

**表 2 · OCF 归因桥（逐年）：** 净利润 → +折旧摊销等非现金项目 → ±营运资本变动（应收、存货、应付分别列示）→ 经营现金流。识别长期吞噬现金的科目。

**表 3 · 营运资本周转天数（3-5 年）：** 应收账款周转天数、存货周转天数、应付账款周转天数。

- **红旗**：收现比持续 <1 且下滑；经营现金流/净利润长期 <0.7；应收周转天数连续上升且收入增速放缓。
- **结论段（必写）：** 利润的现金含量如何？哪个营运资本科目在吞噬现金？

#### 3.4.3 三表勾稽校验

三项校验（逐年或最新一期）：

1. 营业收入 ×(1+增值税率) ≈ 销售收现 + Δ(应收账款+应收票据)
2. 折旧摊销 vs 资本开支：折旧<资本开支 = 扩张期；长期大幅反向 = 收缩/吃老本，需说明
3. Δ留存收益 ≈ 净利润 − 分红 − 回购

- **判定**：勾稽误差 >10% 且无合理解释 → 记红旗（不直接否定报表，扣减 §3.5"会计诚信"维度）。
- **结论段（必写）：** 三表之间逻辑自洽吗？有没有解释不了的缺口？

#### 3.4.4 资产负债表质量

**模板（最新一期 + 必要年份趋势）：**

| 指标 | 数值 |
|---|---|
| 有息负债总额 / 短债占比 | |
| 货币资金 / 货币资金÷短期有息负债 | |
| 流动比率 / 速动比率 | |
| 利息覆盖倍数（EBIT/利息支出） | |

- **压力测试**：收入 −20% 情景下重算利息覆盖倍数（假设利润率同比例压缩）。
- **红旗**：短债占比 >70%；货币资金 < 短期有息负债；利息覆盖倍数 <2。
- **结论段（必写）：** 资产负债表是赋能还是脆弱？融资收紧时会怎样？

### 3.5 财务质量评分卡与估值传导

**六维评分**（每维 1-5 分，等权，总分 30。**每维必附依据**：指标名+数值+年份+证据等级，禁止无依据打分）：

| 维度 | 评分（1-5） | 依据（指标名 + 数值 + 年份 + 证据等级） |
|---|---|---|
| 盈利质量 | | |
| 现金质量 | | |
| 资产负债 | | |
| 会计诚信 | | |
| 资本配置 | | |
| 趋势方向 | | |

**各维度考察内容：**

| 维度 | 考察指标 |
|---|---|
| 盈利质量 | 净利率水平与趋势、非经常损益占比、毛利率-费用率剪刀差 |
| 现金质量 | 收现比、OCF/净利润、FCF 转换率 |
| 资产负债 | 周转效率、有息负债结构、偿债能力 |
| 会计诚信 | 勾稽校验结果、审计意见、会计政策激进程度 |
| 资本配置 | 增量 ROIC、回购/分红 vs 稀释、并购记录 |
| 趋势方向 | 上述维度近 3 年的方向性变化（改善/持平/恶化） |

**等级划分**：A ≥24 分；B 18-23；C 12-17；D <12。数据不足的维度按 1 分计入总分（可标注"不可评"），且结论置信度上限降一档。

**映射规则（质量等级 → 估值参数）：**

| 质量等级 | 情景概率调整 | 估值倍数取位 | 买入最低安全边际 | 仓位上限 |
|---|---|---|---|---|
| A | 不调整 | 区间内自由 | >0%（保守价值>现价） | 原上限 |
| B | 保守 +10pp、基准 −10pp | 区间中位及以下 | ≥ +5% | 原上限 |
| C | 保守 +15pp、基准 −5pp、乐观 −10pp | 区间下沿 | ≥ +10% | 减半 |
| D | 仅保守情景且概率 ≥60% | 仅作参考上限 | **不买入** | 0（观察/退出触发） |

（概率调整后三情景合计仍为 100%。）

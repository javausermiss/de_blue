## 1. 背景与目标

用户对 stock-analyzer 技能（SKILL.md）的财报分析部分不满意，痛点定位为三处：

1. **分析深度**：§3 只有"三个结论 + 会计检查"两张表，缺少深层财务分析工具
2. **报告呈现**：财报部分定性话多定量少，不够专业
3. **结论衔接**：财务分析结论没有显式传导到 Phase 2 估值锁参

目标：把"深度工具 → 标准呈现 → 评分卡 → 估值锁参"串成一条硬约束链，一次改透。

## 3. 设计详述

### 3.1 框架_v5.md §3.4：四项深度财务分析

现有 §3.1~3.3 保留不动。新增 §3.4，每项工具 = **标准模板表 + 红旗阈值 + 结论段**，三部分缺一不可。

#### 3.4.1 杜邦分解

**模板**（3-5 年逐年）：

| 年份 | ROE | 净利率 | 总资产周转率 | 权益乘数 |
|---|---|---|---|---|

- 每年对上一年的 ΔROE 做**贡献分解**：净利率贡献、周转率贡献、杠杆贡献（用连环替代法，说明方法）
- **红旗**：ROE 提升主要由权益乘数上升驱动，且净利率或周转率在下降
- **结论段**（必写）："ROE 变动的真正驱动是谁？该驱动可持续吗？"

#### 3.4.2 利润与现金流质量

**表 1 · 利润现金含量**（3-5 年）：收现比（销售商品提供劳务收到的现金/营业收入）、OCF/净利润、剔非净利率（扣除非经常损益后）

**表 2 · OCF 归因桥**（逐年）：净利润 → +折旧摊销等非现金项目 → ±营运资本变动（应收/存货/应付分别列示）→ 经营现金流。识别长期吞噬现金的科目。

**表 3 · 营运资本周转天数**（3-5 年）：应收账款周转天数、存货周转天数、应付账款周转天数

- **红旗**：收现比持续 <1 且下滑；OCF/净利润长期 <0.7；应收周转天数连续上升且收入增速放缓
- **结论段**（必写）："利润的现金含量如何？哪个营运资本科目在吞噬现金？"

#### 3.4.3 三表勾稽校验

三项校验，逐年或最新一期：

1. 营业收入 × (1+增值税率) ≈ 销售收现 + Δ(应收账款+应收票据)
2. 折旧摊销 vs 资本开支（折旧<资本开支=扩张；长期大幅反向=收缩/吃老本，需说明）
3. Δ留存收益 ≈ 净利润 − 分红 − 回购

- **判定**：勾稽误差 >10% 且无合理解释 → 记红旗（不直接否定报表）
- **结论段**（必写）："三表之间逻辑自洽吗？有没有解释不了的缺口？"

#### 3.4.4 资产负债表质量

**模板**（最新一期 + 必要年份趋势）：

| 指标 | 数值 |
|---|---|
| 有息负债总额 / 短债占比 | |
| 货币资金 / 货币资金÷短期有息负债 | |
| 流动比率 / 速动比率 | |
| 利息覆盖倍数（EBIT/利息支出） | |

- **压力测试**：收入 −20% 情景下重算利息覆盖倍数（假设利润率同比例压缩）
- **红旗**：短债占比 >70%；货币资金 < 短期有息负债；利息覆盖 <2
- **结论段**（必写）："资产负债表是赋能还是脆弱？融资收紧时会怎样？"

### 3.2 框架_v5.md §3.5：财务质量评分卡与估值传导

**六维评分**，每维 1-5 分，等权，总分 30。**每维打分必附依据**（指标名 + 数值 + 年份 + 证据等级），禁止无依据打分：

| 维度 | 依据示例 |
|---|---|
| 盈利质量 | 净利率水平与趋势、非经常损益占比、毛利率-费用率剪刀差 |
| 现金质量 | 收现比、OCF/净利润、FCF 转换率 |
| 资产负债 | 周转效率、有息负债结构、偿债能力 |
| 会计诚信 | 勾稽校验结果、审计意见、会计政策激进程度 |
| 资本配置 | 增量 ROIC、回购/分红 vs 稀释、并购记录 |
| 趋势方向 | 上述维度近 3 年的方向性变化（改善/持平/恶化） |

**等级划分**：A ≥24 分；B 18-23；C 12-17；D <12。

### 3.3 映射规则表（质量等级 → 估值参数）

| 质量等级 | 情景概率调整 | 估值倍数取位 | 买入最低安全边际 | 仓位上限 |
|---|---|---|---|---|
| A | 不调整 | 区间内自由 | >0%（保守价值>现价） | 原上限 |
| B | 保守 +10pp、基准 −10pp | 区间中位及以下 | ≥ +5% | 原上限 |
| C | 保守 +15pp、基准 −5pp、乐观 −10pp | 区间下沿 | ≥ +10% | 减半 |
| D | 仅保守情景且概率 ≥60% | 仅作参考上限 | **不买入** | 0（观察/退出触发） |

（概率调整后三情景合计仍为 100%。）

**硬约束**：Phase 2 锁参必须引用评分卡结果并按表应用；主会话若要偏离映射，必须在报告中写明偏离理由。

### 3.4 SKILL.md 执行链改动

1. **Phase 1** 财务研究代理采集范围扩写，明确三表科目清单：营业收入、营业成本与毛利率构成、三费、非经常损益、折旧摊销、应收账款+应收票据、存货、应付账款、有息负债（短长分列）、利息支出、资本开支、分红、回购、股本变化——保证四项深度工具有数据可用
2. **Phase 2** 锁参清单新增必输入："财务质量评分卡结果 + 映射应用情况"
3. **Phase 3** 写作代理 B 的 §3 职责扩写：§3.4 四工具（模板+结论段+红旗）+ §3.5 评分卡
4. **Phase 4** QA 清单 18 → 20 项：
   - 19：四项深度工具按模板完成，各附结论段，红旗已标注
   - 20：评分卡已打分且每维有依据，Phase 2 估值已按映射表应用（或写明偏离理由）
5. **Common Mistakes** +2 条："深度工具只填表不写结论段"；"评分卡打分无依据、或未传导到 Phase 2"
6. **CLAUDE.md**："18 项质量检查" → "20 项质量检查"

### 3.5 防编造与数据不足规则

- 某工具数据不足（如港股季报不全）→ 明示"数据不足，跳过"，评分卡对应维度**按 1 分计入总分**（可标注"不可评"），**结论置信度上限降一档**
- 勾稽误差大 → 记入"会计诚信"维度扣分，不直接否定报表
- 深度工具所有数字必须来自 A/B 级证据（财报/行情），推算项标 D 并说明方法
